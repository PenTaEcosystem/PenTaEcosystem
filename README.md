## Who built this?

Not a CS graduate. Not a bootcamp alumni.

Someone who spent years on a factory floor in Japan — where a broken system doesn't fail silently, it stops the entire line. That's where I learned what reliability actually means.

Since 2023, I've been building **the Penta ecosystem**: 10+ interconnected AI products, each one born from a real need.

My mother needed a geometry tool. → I built it.  
I needed to study Japanese. → I built that too.  
My community needed a marketplace that worked without internet. → Built.

No VC funding. No team. No obvious solutions.
