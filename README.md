📐 How I Build
No tutorials. No boilerplate clones.
Each project starts with a problem. Architecture emerges from constraints. Cost and reliability shape every decision — local inference over API bills, SQLite over managed databases when latency allows, offline-first when connectivity is unreliable.
I implement patterns before I know their names. I've shipped multi-agent orchestration, server-client architectures across 3 operating systems, real-time WebSocket audio pipelines, and BLE mesh networks — not from courses, but from needing them to exist.
The non-IT background is a feature, not a gap. Manufacturing teaches you that systems fail in the real world, not in tests.
